# Reglas de Desarrollo para Claude Code

Antes de analizar, sugerir o crear cualquier código en este proyecto, debes leer y asimilar obligatoriamente el archivo `AI_RULES.md`. 

Ese documento maestro define las restricciones de nuestra arquitectura modular (Clean Architecture), la separación estricta de responsabilidades en la carpeta `src/` y el patrón de inyección de dependencias. No inicies ninguna tarea sin haber procesado previamente esas reglas.
